# Лабораторная работа №1: ООП в Python

**Предметная область:** Магазин музыкальных инструментов. 

**Выполнила:** Борисоглебская Полина
## Описание
Проект представляет собой консольное приложение для управления музыкальным магазином. Реализована объектно-ориентированная модель с наследованием, инкапсуляцией и полиморфизмом, а также механизмы сохранения данных в форматы JSON и XML.

## Навигация по репозиторию
- **[Исходный код (main.py)](./main.py)** — вся логика программы в одном файле.
- **[UML-диаграмма классов](./uml1.pdf)** — визуальное представление архитектуры.
- **[Отчет о выполнении](./ppLab1.docx)** — оформленный отчет для сдачи.
- **[Файл данных JSON](./data/data.json)** — пример сохраненных данных.
- **[Файл данных XML](./data/data.xml)** — пример сохраненных данных.
  
## Реализованный функционал:
- Иерархия классов (`Instrument` -> `Guitar`, `Drum`, `Keyboard`).
- CRUD операции (добавление, просмотр, удаление) через класс `Inventory`.
- Пользовательские исключения (`ShopError`, `ItemNotFoundError`).
- Сохранение и загрузка данных в форматы **JSON** и **XML**.
- Консольный интерфейс с защитой от ошибок ввода (try/except).

## Результаты работы
Программа успешно проходит все этапы проверки:
- Создание объектов и проверка наследования (`Instrument` -> `Guitar`, `Drum`, `Keyboard`).
- Выполнение CRUD-операций (добавление, поиск, удаление) через класс `Inventory`.
- Корректная обработка ошибок ввода (перехват `ValueError` и собственных исключений `ShopError`).
