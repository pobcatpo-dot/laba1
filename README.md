## Описание
Проект представляет собой консольное приложение для управления музыкальным магазином. Реализована объектно-ориентированная модель с наследованием, инкапсуляцией и полиморфизмом, а также механизмы сохранения данных в форматы JSON и XML.

## Реализованный функционал:
- Иерархия классов (`Instrument` -> `Guitar`, `Drum`, `Keyboard`).
- CRUD операции (добавление, просмотр, удаление) через класс `Inventory`.
- Пользовательские исключения (`ShopError`, `ItemNotFoundError`).
- Сохранение и загрузка данных в форматы **JSON** и **XML**.
- Консольный интерфейс с защитой от ошибок ввода (try/except).
